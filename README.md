Professional Portfolio Web Application for **Akanksha Srivastava** — Clinical Research Operations & Project Coordination.

## 🚀 Overview
- **Domain**: Clinical Project Coordination | Clinical Trial Operations | Site Services | Lab Project Execution
- **Experience**: 6+ Years at ICON plc (2020 – Present)
- **Tech Stack**: React 19, Vite, Vanilla CSS (Design Tokens, Dark/Light Mode), Lucide Icons

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
